# RedSpark-1.0-FlashLight-Preview

![RedSpark 赤霄初耀](../assets/redspark-logo.png)

RedSpark 的当前模型产品名。该版本基于上游最终后训练模型 `openbmb/MiniCPM5-2B`，用于开源软件知识与代码问答方向的领域 SFT。

目录中的 MiniCPM 模型卡、许可证和配置文件保持上游内容，用于记录模型结构、权重来源和使用边界；RedSpark 自有训练、推理和数据飞轮代码位于仓库其他目录。

模型资产目录中的 README 在顶部增加了 RedSpark 本地产品说明，并保留 MiniCPM 官方模型卡链接。这样既能以 RedSpark 名称使用模型，也不会混淆上游模型身份、许可证和技术信息。
