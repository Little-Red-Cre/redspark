# RedSpark-1.0-FlashLight-Preview

![RedSpark 赤霄初耀](../assets/redspark-logo.png)

RedSpark 的当前模型产品名。该版本基于上游指令模型 `Qwen/Qwen3-1.7B`，用于开源软件知识与代码问答方向的领域 SFT。

目录中的 Qwen 模型卡、许可证和配置文件保持上游内容，用于记录模型结构、权重来源和使用边界；RedSpark 自有训练、推理和数据飞轮代码位于仓库其他目录。

模型资产目录中的 README 在顶部增加了 RedSpark 本地产品说明，后半部分保留 Qwen 官方模型卡。这样既能以 RedSpark 名称使用模型，也不会混淆上游模型身份、许可证和技术信息。
